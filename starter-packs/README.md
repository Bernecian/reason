# Starter packs

Drop-in `.r/rules.yaml` files for common stacks. Copy one, tailor keywords and load paths to your layout, and commit it to your repo.

Every pack ships with `run:` examples **commented out and with `trust` omitted**. Read each command, flip `trust: true` only if you're happy with it, then uncomment.

| Pack | For |
|---|---|
| `nextjs.yaml` | Next.js app + shared components + API routes |
| `react-native.yaml` | Expo / bare React Native with TypeScript |
| `fastapi.yaml` | Python FastAPI backend |
| `node-api.yaml` | Node + TypeScript API (Fastify / Express / Hono) |
| `rust.yaml` | Rust workspace (Cargo) |
| `monorepo.yaml` | Generic pnpm / turbo monorepo |
